# Haunted Manor: Party for the Marionette

A **text-based adventure game** written in Python, originally created as a class project for SNHU’s *Introduction to Scripting* course.

## 🎮 Game Concept

Blackwood Manor is cursed. Haunted by a forgotten entity known only as **The Marionette**, you—a paranormal investigator—must explore the mansion, collect sacred items, and throw her a party to free the trapped souls inside.

But beware: entering the Grand Hall before you’re ready may cost you everything...

## 🧭 Game Features

- Room-based navigation system
- Collectible item mechanic (inventory)
- Conditional win/lose outcomes
- One-way secret passage challenge
- Eerie atmosphere with thematic items and locations

## 🗺️ Rooms

- Foyer
- Library
- Kitchen
- Parlor
- Dining Room
- Study
- Attic
- Secret Passage (one-way only)
- Grand Hall (final room)

## 🛠️ How to Play

- Use commands like `go North`, `go South`, etc.
- Pick up items using `get 'item name'`
- Type `exit` to quit
- Explore all rooms and gather 6 unique items before facing The Marionette

- Python 3.x
